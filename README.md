# 🚀 Diamante Auto Transfer Bot

Automated transaction tool untuk Diamante Testnet campaign. Bot ini dirancang untuk memudahkan transfer otomatis dengan fitur lengkap dan reliable.

---

## 📋 Tentang Diamante Testnet

**Diamante** adalah blockchain testnet yang mengadakan campaign menarik dengan sistem tier rewards. Semakin banyak transaksi, semakin besar reward yang didapat!

## ✨ Fitur Utama

- **💰 Cek Balance** - Lihat saldo wallet Diamante Anda
- **🚰 Claim Faucet** - Klaim token dari faucet setiap hari
- **📤 Transfer Otomatis** - Transfer ke multiple wallets dengan mudah
- **🔄 Auto Retry** - Retry otomatis jika ada error (up to 500x)
- **📊 Analytics** - Tracking transaksi dan statistik lengkap
- **💬 Live Chat** - Support real-time untuk bantuan
- **📢 Broadcast** - Kirim pesan ke multiple user

---

## 🚀 Cara Registrasi

1. **Koneksikan Wallet** - Hubungkan wallet testnet Anda
2. **Claim Faucet** - Klaim token awal untuk mulai
3. **Kirim ke Teman** - Transfer ke teman untuk naik tier
4. **Selesai!** ✅
